## 🧪 3. 실사용성(Usability) 및 행정 정합성 실측 평가

### 🟢 1) 지자체 행정 공무원 관점의 실사용성 (Rating: 4.9 / 5.0)
- **실질 건축 적지 우선 추천 (v4.2.0 완공)**:
  기존 공간 데이터의 도로('도') 지목 편향을 완전 수술하여, 실제 인허가 및 건립이 100% 가능한 **대지('대'), 잡종지('잡'), 공공용지('공') 부지를 최우선 1순위로 추천**합니다.
- **RAG 조례 PDF 자동 분석 및 바인딩**:
  지자체 담당자가 구청 자치법규 조례 PDF 문서를 업로드하면, pgvector 1,536차원 벡터 DB로 즉시 인덱싱되어 심의 토론 시 조례 조항이 자동 인용됩니다.
- **행정 의결서 문서(DOCX/PDF) 자동 출력**:
  심의 완료 후 버튼 클릭 한 번으로 **지자체 제출용 정식 행정 의결서 보고서**가 자동 생성되며, 하단에 SHA-256 무결성 검증 씰이 보증됩니다.

## 🚀 4. 상용 배포(Deployment) 환경 준비 가이드

### 🖥️ 1) 권장 클라우드 인프라 스펙 (AWS / NCP / GCP)
- **Virtual Server Spec**:
  - **OS**: Ubuntu 22.04 LTS (64-bit)
  - **vCPU**: 2 vCPU 이상 (권장 4 vCPU)
  - **RAM**: 4GB 이상 (권장 8GB - XGBoost ML 및 GeoPandas 인메모리 안정성)
  - **Storage**: SSD 50GB 이상
  - **Network**: HTTP(80), HTTPS(443), Backend API(8000) 포트 개방

### 🐳 2) 도커 배포 3단계 순서 (5초 배포 절차)
1. **서버 환경 구성**:
   ```bash
   sudo apt-get update && sudo apt-get install -y docker.io docker-compose
   ```
2. **프로젝트 환경 변수 설정 (`.env`)**:
   ```env
   POSTGRES_DB=postgres
   POSTGRES_USER=Admin
   POSTGRES_PASSWORD=admin1234
   OPENAI_API_KEY=sk-... (실제 API 키)
   ```
3. **도커 컨테이너 일괄 시동**:
   ```bash
   docker-compose up -d --build
   ```
