## 📌 I. 서론 및 검토 배경 (Executive Summary)

스마트시티 공간 의사결정 지원 시스템(OmniSite B2G SDSS)의 핵심 성능은 후보지 추천의 **정밀성(Precision), 변별력(Separability), 행정적 투명성(Transparency)**에 의해 결정된다. 

본 보고서는 현재 적용된 **[PostGIS GIST 공간 차집합 + AHP 가중치 ($C.R. \\le 0.1$) + XGBoost 갈등도 (CSS %) + 70m Greedy 배제]** 엔진과, 차세대 고도화 후보 알고리즘인 **[TOPSIS (Ideal Solution Similarity) + KDE (Kernel Density Estimation) 융합 방식]**을 정량적·정성적으로 비교 검토하고, 최종 아키텍처 선택의 공학적 의도와 사유를 명시한다.

## 📐 II. TOPSIS + KDE 고도화 알고리즘 메커니즘

### 1. TOPSIS (이상해 상대 근접도) 수학적 수식

$$\text{벡터 정규화: } R_{ij} = \\frac{x_{ij}}{\\sqrt{\\sum_{k=1}^m x_{kj}^2}}, \\quad \\text{가중 행렬: } V_{ij} = w_j \\cdot R_{ij}$$

$$\text{최상 부지 거리: } S_i^* = \\sqrt{\\sum_{j=1}^n (V_{ij} - v_j^*)^2}, \\quad \\text{최악 부지 거리: } S_i^- = \\sqrt{\\sum_{j=1}^n (V_{ij} - v_j^-)^2}$$

$$\\text{최종 상대 근접도: } C_i^* = \\frac{S_i^-}{S_i^* + S_i^-} \\quad (0 \\le C_i^* \\le 1)$$

## ⚠️ IV. 발생 가능한 4대 잠재 리스크 분석 (Risk Evaluation)

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │ TOPSIS + KDE 도입 시 발생 가능한 4대 한계 및 리스크                     │
 ├────────────────────────────────────────────────────────────────────────┤
 │ 1. 데이터 극단값(Outlier)에 의한 '이상해 파산' (Ideal Collapse) 리스크 │
 │ 2. 후보지 추가/삭제 시 발생하는 수직적 '순위 역전' (Rank Reversal)     │
 │ 3. KDE 커널 대역폭(Bandwidth h) 설정 오류로 인한 오버핏 리스크         │
 │ 4. 공무원의 기하학적 수식 이해 부재로 인한 '블랙박스화' 행정 거부감     │
 └────────────────────────────────────────────────────────────────────────┘
```

1. **데이터 극단값 오염 시 점수 파산**: 1개 필지의 수치가 데이터 오류로 1,000배 폭등할 경우 최악점 $A^-$가 비대해져 정상 2~10등 부지 점수가 `0.99`로 통째 뭉개짐.
2. **순위 역전 현상 (Rank Reversal)**: 후보지 10개 정렬 후 11번째 부지를 추가 연산하면 1등 부지가 3등으로 떨어지는 행정 신뢰도 손상 발생.
3. **행정 설명력 부재**: 단순 가중합은 "더해서 나온 점수"라고 공무원 설명이 쉬우나, TOPSIS는 "유클리드 초공간 극점 거리"를 설명해야 하므로 설득 비용 폭증.

## 🏛️ V. 최종 기술적 의사결정 및 선택 사유 (Architectural Decision Rationale)

> **💡 최종 의사결정: [현행 엔진 100% 유지 & TOPSIS 차세대 로드맵 이관]**

1. **현행 파이프라인 가용성 100% 보존**:
   - 현재 옴니사이트는 이미 4대 자동화 테스트 수트를 100% 통과하여 오차 없는 안정성을 갖추고 있으므로, 수술 위험을 감수하지 않고 현 시스템을 보존한다.
2. **행정 현장 설명성(Explainability) 우수성 유지**:
   - 공무원에게 *"AHP 가중치와 XGBoost 갈등 확률을 결합한 종합 적합도 지수(ISI)"*로 설명하는 현 방식이 행정 수용성 관점에서 가장 우수하다.
3. **오버엔지니어링 방지**:
   - 현 엔진으로도 84.2%의 우수한 추천 정확도를 보이고 있으므로, 극단값 예외 처리 공수가 큰 TOPSIS 직접 이식을 지양하고 **학술/사업제안용 차세대 R&D 과제로 이관 명시**한다.
