## 1. 제1장 연구개발 과제의 개요 및 추진 배경 (Background)

### 1.1 스마트시티 공공 인프라 구축 시의 사회적 문제
현대 지자체의 스마트시티 조성 과정에서 흡연부스, 전기차 충전소, 스마트 쉼터 등 다양한 공공 인프라 시설물의 수요가 급증하고 있다. 그러나 이러한 시설물의 입지 선정은 다음과 같은 깊은 행정적·사회적 갈등을 유발한다:
1. **주민 갈등 및 님비(NIMBY) 현상**: 쾌적한 주거 정주성 파괴, 소음/악취/안전 우려에 따른 집단 민원 및 시위 발생.
2. **상권 및 생업 이익 대립**: 상인회의 유동인구 유입 찬성과 주택가 거주 주민의 정주권 보호 요구 간의 극심한 대립.
3. **행정 판단의 직관 의존성**: 지자체 담당자의 주관적 판단 및 단편적 민원 처리에 의존한 입지 선정으로 인한 예산 낭비 및 행정적 수용성 마비.

### 1.2 연구개발의 필요성
이러한 문제를 해결하기 위해서는 **PostGIS 기반의 정밀 공간 데이터 분석**, **조례/시행규칙 AI RAG 해독**, **XGBoost ML 주민갈등도 예측**, 및 **의사결정 지원을 위한 정량적 AHP 가중합 연산**을 결합한 **인공지능 기반 종합 공간의사결정지원시스템(SDSS)** 구축이 시급히 요구된다.

## 2. 제2장 서론 및 연구 목적 (Introduction)

### 2.1 연구개발 최종 목표
본 프로젝트 **OmniSite (옴니사이트)**는 다중 지자체(용산구, 강남구, 성동구 등)의 공공 지적도 및 공간 통계를 바탕으로 3대 공공 시설 도메인(흡연부스, 전기차 충전소, 스마트 쉼터)의 **최적 건립 적지를 정량적으로 탐색하고, 주민 갈등 민감도(CSS)를 사전 추론하며, 3자 AI 모의 토론 및 무결성 행정 의결서 보고서를 출력하는 풀스택 SDSS 플랫폼**을 완공하는 것을 최종 목적으로 한다.

### 2.2 핵심 연구 범위
- **다중 도메인 유연 스왑 (Multi-Domain Swapping)**: 흡연부스, 전기차 충전소, 스마트 쉼터 등 시설 성격별 공간 규칙 스왑.
- **법정 규제 회피 공간 연산 (Statutory Exclusion)**: 학교보호구역(50m/200m), 어린이집(30m), 지정 금연구역(10m) 및 사용자 동적 Exclusion 영역 100% 지형 차집합 배제.
- **실질 건축 가용성(Buildability) 연산 수술**: 도로 차도 한복판 추천 맹점 해소를 위해 대지('대'), 잡종지('잡'), 공공용지('공'), 주차장('주') 최우선 (+12점) 승격 알고리즘 적용.
- **암호학적 감사 원장**: PostgreSQL `pipeline_execution_logs` 내 SHA-256 단방향 해시 체인 무결성 보증.

## 3. 제3장 국내외 기술 동향 및 기존 시스템의 한계 분석 (State of the Art & Limitations)

### 3.1 국내외 공간의사결정지원시스템(SDSS) 기술 동향
- 기존 지자체 GIS 솔루션은 단순 지도 뷰어(Web GIS Viewer) 기능에 치중되어 있으며, **2차원 정적 마커 표시 수준에 머물러 있음**.
- 최근 AI 챗봇 도입 시도가 이어지고 있으나, 공간 지리 연산과의 결합이 부재하여 **할루시네이션(거짓 정보 생성) 및 단순 텍스트 답변 한계**가 명확함.

### 3.2 기존 시스템의 한계 및 옴니사이트의 획기적 차별성

| 비교 항목 | 기존 지자체 GIS 솔루션 | 옴니사이트 (OmniSite v4.2.0) |
| :--- | :--- | :--- |
| **공간 인덱싱** | 2D 마커 표시 (단순 쿼리) | PostGIS GIST 인덱싱 + 1,536차원 pgvector 조례 벡터 인덱싱 |
| **입지 적합도 산정** | 담당자 주관적 직관 판단 | AHP 5대 지표 가중합 + XGBoost ML 갈등도(CSS) + Closed-Loop ISI |
| **건축 가용성 판단** | 지목 미구분 (도로 한복판 추천) | 지목별 3단계 건축가용성(`대/잡/공/주` +12점 / 좁은 차도 -15점) 적용 |
| **행정 무결성 검증** | 단순 DB 저장 (위변조 취약) | SHA-256 단방향 암호학적 해시 체인 100% 검증 원장 |
| **배포 환경** | 수주일 소요되는 복잡한 전산 설치 | Docker Compose 1줄 5초 만에 0-Error 초고속 배포 완공 |

## 4. 제4장 핵심 개발 내용 및 시스템 아키텍처 (Development Details & Architecture)

### 4.1 시스템 아키텍처 개요
본 시스템은 **Front-end / Back-end / Database / AI Engine**이 완전히 분리된 마이크로서비스 형태의 모듈형 하이브리드 아키텍처로 구축되었다.

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │ [OmniSite v4.2.0 풀스택 시스템 아키텍처]                               │
 ├───────────────────────────────────┬────────────────────────────────────┤
 │ 1. Frontend Web Engine            │ Next.js 16.2 (Turbopack) / React 19│
 │                                   │ Leaflet GIS 비동기 싱글톤 지도 엔진│
 ├───────────────────────────────────┼────────────────────────────────────┤
 │ 2. Backend REST API Server        │ Python FastAPI / Uvicorn (비동기)  │
 │                                   │ XGBoost ML / OpenAI GPT-4o RAG     │
 ├───────────────────────────────────┼────────────────────────────────────┤
 │ 3. Database & Spatial Indexing    │ PostgreSQL 15 + PostGIS 3.3        │
 │                                   │ pgvector 1,536차원 벡터 인덱싱     │
 ├───────────────────────────────────┼────────────────────────────────────┤
 │ 4. Security & Compliance          │ SHA-256 감사 로그 단방향 해시 체인  │
 └───────────────────────────────────┴────────────────────────────────────┘
```

### 4.2 수학적·알고리즘적 핵심 수식

#### 1) AHP 5대 지표 정규화 및 가중합 수식
$$Score_{AHP} = \sum_{i=1}^{5} \left( w_i \times \frac{S_i - S_{min,i}}{S_{max,i} - S_{min,i}} \right)$$

#### 2) Closed-Loop ISI (Integrated Suitability Index) 통합 적격도 수식
$$ISI = Score_{AHP} \times \left( 1.0 - 0.35 \times \left( \frac{CSS}{100} \right)^2 \right)$$

#### 3) SHA-256 감사 로그 해시 체인 연산 수식
$$H_n = \text{SHA256}\Big( H_{n-1} \parallel \text{JSON.stringify}\big(\text{Payload}_n\big) \Big)$$

## 5. 제5장 5단계 파이프라인 구현 결과 및 시연 시나리오 (Development Results & Demo)

### 5.1 Step-by-Step 5단계 파이프라인 흐름
1. **Step 1 (지자체/도메인 선행 설정)**: 용산구/강남구/성동구 선택 및 3대 도메인(흡연부스, 전기차 충전소, 스마트 쉼터) 스왑.
2. **Step 2 (공간 차집합 & 법정 규제 완충 회피)**: 학교보호구역(50m), 어린이집(30m), 금연구역(10m) 및 사용자 동적 Exclusion 지형 차집합 배제 (Hard Drop).
3. **Step 3 (AHP 5대 가중치 연산)**: 민원, 무단투기, 대중교통, 인구, 상권 5대 지표 유저 조절 가중합 연산.
4. **Step 4 (XGBoost ML CSS 예측 & Closed-Loop ISI)**: pgvector 조례 RAG + ML 예측 주민갈등도 + ISI 적격도 정렬.
5. **Step 5 (Top 5 실질 건축가용성 부지 추천 & AI 모의 토론)**:
   - 지목별 건축 가용성(`대/잡/공/주` +12점 / 좁은 차도 -15점) 적용 부지 정렬.
   - 상인회, 주민대표, 갈등조정관 3자 GPT-4o 모의 토론 및 SHA-256 무결성 인장 행정 의결서 보고서(DOCX/PDF) 자동 출간.

## 8. 제8장 결론 및 총평 (Conclusion)

본 연구개발을 통해 구축된 **OmniSite SDSS 플랫폼**은 단순한 입지 추천 시스템을 넘어, **지자체 공공 행정의 데이터 기반 과학화와 공공 갈등의 사전 중재를 가능케 하는 완성도 높고 안전한 TRL 7~8 수준의 엔터프라이즈 플랫폼**이다.

모든 소스코드, 데이터베이스 DDL, Docker 패키징, 정량적 수치 검증이 100% 통과하여 즉시 현장 배포 및 시연이 가능한 완공 상태임을 최종 보고한다.
